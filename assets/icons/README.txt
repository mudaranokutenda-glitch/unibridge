AZSA icons (optional)
=========================

Put your own icons in this folder. The app uses them when the file exists.
If a file is missing, the app shows a normal Material icon instead (nothing breaks).

File names (exactly, all lower case):
  rates.png            the exchange rates button (top right of the Requests screen)
  marketplace.png      the Marketplace tab
  student_space.png    the Student space tab
  profile.png          the Profile tab

Format: PNG, 128 x 128 pixels, transparent background.
Draw the icon in one colour with some empty space around it (about 12 pixels).
A dark grey or sky blue icon works on the light theme.

After you add or change a file: stop the app and run "flutter run" again
(a hot reload does not see new files).
