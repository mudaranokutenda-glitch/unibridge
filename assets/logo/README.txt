AZSA logo
=========

logo.jpg   the full AZSA logo (cap, circle and ribbon) on white.
           Shown big on the white start-up screen (lib/intro.dart).

To change it: replace logo.jpg with a new picture with the same name
(white background, any size around 800 x 1000), then stop the app and
run "flutter run" again (a hot reload does not see new files).
The app icon is a different file: assets/icon/icon.png (see pubspec.yaml).
